Spiral Weather + Sleep Tracker

A clock-based spiral visualization that turns weather + user-entered sleep into a quick “at-a-glance” daily read. Built for CMU 15-113 HW4 by deploying a Flask backend (Render) and connecting it to a deployed frontend.

Overview

This project was created for CMU 15-113 HW4, which focuses on creating a backend service, deploying it, and connecting it to a frontend. I used this assignment to build on a previous design-class concept: a spiral “clockface” that visualizes sleep periods and temperature across the day for quick understanding.

The backend proxies and normalizes hourly temperature data from Open-Meteo, and the frontend renders the spiral by mapping temperature to a color gradient and sleep periods to dark gray.

  • Goal: Turn a conceptual design into a working full-stack app with a deployed backend + frontend.
  • Backend: Flask API deployed on Render.
  • Data source: Open-Meteo hourly temperature endpoint.
  • Frontend output: A spiral “clock” that shows future time (light gray), sleep (dark gray), and awake temperature (color gradient) minute-by-minute.

Process

I approached HW4 in two tracks: (1) stabilize the spiral visualization and data model on the frontend, then (2) build a backend that serves weather data to the frontend in a clean, consistent format.

  • Step 1 — Spiral MVP: Render a 24-hour spiral clockface with minute-level segments and a “current time” marker.
  • Step 2 — Sleep + temperature mapping: Map sleep minutes to dark gray, and awake minutes to a temperature gradient using interpolation between hourly values.
  • Step 3 — Backend API: Implement /api/hourly that accepts lat/lon and returns 24 hourly temps starting at local midnight.
  • Step 4 — Deploy + connect: Deploy backend to Render, enable CORS, then update the frontend to fetch from the deployed endpoint.
  • Step 5 — Documentation: Write README with endpoint docs, setup instructions, and prompt log (AI usage).

Outcome

  • Deployed Flask backend on Render that returns normalized hourly temperatures (24 values from local midnight)
  • Frontend fetches backend data and renders minute-level spiral progress with a cold-to-hot gradient
  • Sleep window overlay using user-entered bedtime and wake time
  • Clear separation of concerns: backend handles external API requests; frontend handles visualization

Skills: backend API design, deployment (Render), frontend-backend integration, and translating a design concept into a functional interactive visualization.
